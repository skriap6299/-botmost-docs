# BotMost — Автоматизация публикации

Данное программное обеспечение (приложение) предназначено исключительно для автоматизации личных задач пользователя (ретрансляция и публикация видеоконтента из Telegram в TikTok).

## Условия использования
* Приложение используется владельцем для личных целей.
* Автор не несет ответственности за сбои в работе сторонних API.

## Политика конфиденциальности
* Приложение не собирает, не сохраняет и не обрабатывает персональные данные третьих лиц или пользователей TikTok.
* Все операции выполняются через официальные авторизованные токены доступа владельца аккаунта.
